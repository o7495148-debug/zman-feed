# פיד טלגרם לזמן ימין

הפרויקט הזה מושך כל 20 דקות את הפוסטים מ-24 השעות האחרונות מערוצי הטלגרם שהסוכן עוקב אחריהם, וכותב אותם לקובץ `feed.json`. לכל פוסט נשמרים תאריך ושעה מדויקים בשעון ישראל, צפיות, צפיות לשעה, שיתופים, ריאקציות, סוג המדיה, אורך הסרטון והטקסט המלא. הסוכן של Claude קורא את הקובץ הזה במקום לפתוח את דפי הטלגרם.

הכול רץ בחינם על השרתים של GitHub, בלי טלפון או מחשב דלוק.

## הקמה (פעם אחת, בערך 20 דקות)

### 1. מפתחות מטלגרם
1. נכנסים ל-https://my.telegram.org עם מספר הטלפון של חשבון הטלגרם.
2. בוחרים API development tools.
3. ממלאים שם לאפליקציה (למשל zmanfeed) ושומרים.
4. מעתיקים את **App api_id** (מספר) ואת **App api_hash** (מחרוזת ארוכה).

### 2. התחברות חד-פעמית (Google Colab)
1. נכנסים ל-https://colab.research.google.com ופותחים מחברת חדשה.
2. בתא הראשון כותבים `!pip install telethon==1.36.0` ומריצים.
3. בתא השני מדביקים את כל התוכן של `login_colab.py` ומריצים.
4. מכניסים את ה-api_id, את ה-api_hash, את מספר הטלפון (+972...) ואת הקוד שטלגרם שולח באפליקציה.
5. מעתיקים את המחרוזת הארוכה שמודפסת. זה ה-TG_SESSION.

### 3. מאגר ב-GitHub
1. פותחים חשבון ב-https://github.com אם אין.
2. יוצרים מאגר חדש (New repository), למשל `zman-feed`, ובוחרים **Public**. הקובץ מכיל רק פוסטים מערוצים ציבוריים, ומאגר ציבורי מאפשר לסוכן לקרוא אותו בלי סיסמה.
3. מעלים את כל הקבצים מהתיקייה הזו (Add file ← Upload files), כולל התיקייה `.github/workflows`.

### 4. סודות
ב-Settings ← Secrets and variables ← Actions ← New repository secret מוסיפים שלושה:
- `TG_API_ID`
- `TG_API_HASH`
- `TG_SESSION`

הסודות האלה לא נראים לאף אחד, גם במאגר ציבורי.

### 5. הפעלה
ב-Actions ← telegram-feed ← Run workflow. אחרי דקה-שתיים אמור להופיע `feed.json` מעודכן במאגר. מאז זה רץ לבד כל 20 דקות.

## הוספה או הורדה של ערוץ
עורכים את הרשימה `CHANNELS` בראש `fetch.py`.

## אבטחה
- ה-TG_SESSION הוא מפתח מלא לחשבון הטלגרם. לא משתפים אותו ושומרים אותו רק ב-Secrets.
- מומלץ להשתמש בחשבון טלגרם משני (עם מספר נוסף) שמצטרף לערוצים, ולא בחשבון האישי.
- כדי לנתק בכל רגע: בטלגרם ← הגדרות ← מכשירים, ולסגור את החיבור.
